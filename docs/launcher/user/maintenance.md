# 更新、修复与卸载

**启动器版本、核心程序提交和运行组件版本彼此独立。** 更新启动器二进制不会自动重装所有 Git/ADB、Python 或核心代码；修改核心版本也不代表桌面启动器必须同步升级。

## 检查与切换版本

在首页检查启动器更新，在「设置」中选择 `stable`（正式版，默认）或 `canary`（测试构建）。下载源选自动、官方、GitHub、Cloudflare CDN；失败时可尝试其他源。Canary 更频繁变动，但清单没有 Canary 构建时不会提示可用更新。发现更新后可使用首页入口执行；下载经过 SHA-256 校验。

设置还能分别指定组件下载、Python 与 PyPI 镜像，以及背景音乐、减弱动态效果和阻止计算机自动睡眠。音频开关默认关闭；降低动态效果可暂停背景视频，视频在窗口隐藏时也会暂停。阻止睡眠不等于强制屏幕常亮。

## 部署、启动和修复的区别

| 操作 | 会发生什么 | 数据影响 |
| --- | --- | --- |
| 「部署」 | 下载 Git／ADB 及 deploy 引导文件 | 不删除核心配置 |
| 「启动」 | 安装／复用 Python、更新核心源码、同步依赖、构建 WebUI、启动后端 | 复用现有运行数据 |
| 「环境修复」 | 重新下载组件并重建 `.venv` | 保留代码、`config/` 和 `log/` |
| 启动器自更新 | 下载新启动器载荷并替换二进制 | 不应删除用户配置 |

运行中的后端需先停止才能执行环境修复。**不要为了修复问题直接删除整个目录或使用 `git reset --hard`**；先用首页修复入口、检查日志和备份用户数据。Git/ADB 放在 `.azurpilot/tools/`，Python 在 `.venv`；两者不是同一目录。

## 导出诊断日志

首页提供日志压缩包导出和错误详情。压缩包仅收集符合范围的日志，打包在后台线程执行，避免大文件阻塞界面。反馈问题时优先提供日志 ZIP、版本、操作步骤与复现条件；截图不能代替错误日志。提交前仍应检查并移除可能包含个人信息的内容。

## 常见故障

| 问题 | 排查重点 |
| --- | --- |
| 下载提示 429 | 镜像限流；可切换来源或使用内置退避重试 |
| 启动提示缺少 `pyproject.toml` | 核心部署未完成，使用环境修复 |
| 无法同步依赖 | 选择可用 PyPI 镜像，检查 `uv.lock` 与网络 |
| WebUI 构建失败 | Node.js 与前端构建错误 |
| 打不开 WebUI | 后端日志、端口 `22267`、本机连接 |
| macOS 启动失败 | 检查 App 与数据目录迁移、签名／隔离状态 |
| 退出后模拟器被关闭 | 可能是进程组／Job 脱离异常，应连同完整日志报告 |

macOS 新版应用使用 `AzurPilot.app/Contents/AzurPilot` 数据目录，旧版数据会尝试迁移。Windows／Linux 便携包的数据路径不同，迁移前不要直接删除旧目录。

## 迁移与卸载

迁移前停止所有实例，备份 `config/`、统计数据库和需要保留的日志。账号、远程授权和设备路径可能需要在新设备重新配置。卸载前通过托盘明确「退出」，再删除程序目录或使用安装程序的卸载入口。

参见[首次运行](/launcher/user/first-run)、[更新链路](/launcher/developer/update)与[后端生命周期](/launcher/developer/backend-lifecycle)。
