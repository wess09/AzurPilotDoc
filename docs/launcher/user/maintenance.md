# 更新、修复与卸载

**启动器版本、核心程序提交和运行组件版本彼此独立。** 更新启动器二进制不会自动重装所有 Git/ADB、Python 运行时或重置核心代码；修改核心提交也不代表桌面启动器必须同步升级。在源码仓库中，启动器配置基线统一采用 `0.0.0` 模板，发布版则由 CI 自动注入诸如 **3.0.6** 与 **3.0.5** 的 Semantic Version。

## 检查与切换版本

启动器支持双更新通道与灵活的镜像源配置：

- **版本通道**：在「设置」中选择 `stable`（正式版，默认）或 `canary`（测试构建）。发现新版本时首页会自动弹出更新提示，并避免同一版本重复骚扰。若当前通道没有更新版本，则保持静默。
- **更新下载源**：可选自动（`auto`，默认）、官方源（`official`）、GitHub、Cloudflare CDN。自动模式会综合系统原始中文语言与当前时区优先选择最快节点，网络失败时自动按备选顺序退避回退。
- **载荷完整性与安全**：所有更新载荷均需通过 SHA-256 哈希校验；在非 GitHub 官方源拉取二进制时可使用编译期绑定的 mTLS 客户端身份验证。更新过程若被用户取消或中断，将完整保留旧版本，绝不替换为不完整的损坏文件。

「设置」面板还提供独立配置项：
- **组件下载源**：自动 / CNB / GitHub；
- **Python 下载源**：自动 / 南京大学 / 中科大 / 淘宝镜像 / 阿里云 / CNB / Astral 官方；
- **Node.js 下载源**（3.0.6 新增）：自动 / 淘宝镜像 / 南京大学 / 官方源（支持失败自动回退，全源采用官方 SHA-256 强校验）；
- **PyPI 源**：自动 / PyPI 官方 / 清华大学 / 中科大 / 阿里云 / 腾讯云 / 华为云 / 南京大学；
- **界面语言**：简中 / 繁中 / 日 / 英；
- **体验与外观**：播放背景音乐、减弱动态效果（暂停背景动画/视频）、阻止计算机空闲自动睡眠。

## 部署、启动与环境修复的区别

| 操作类别 | 具体执行动作 | 用户数据与配置影响 |
| --- | --- | --- |
| **部署组件** | 读取清单并下载 Git、ADB 及 `deploy/` 引导脚本与模板 | 仅准备外部工具，普通部署只补齐缺失/空文件，不影响核心代码与用户配置 |
| **启动运行** | 检测/复用独立 Python 3.14.3 与 Node.js 运行时（≥22.12.0），更新仓库、`uv sync` 锁定依赖、构建前端并启动后端 | 完整沿用已有数据库与 `config/` 配置 |
| **环境修复**（3.0.5 升级） | 重新下载覆盖 Git/ADB 组件，**重新下载并原子替换全部 `deploy/` 脚本与系统模板**，清理 uv 缓存并重建 `.venv` | **严格保留**其他代码、`config/deploy.yaml`、用户 JSON 配置、日志和清单外文件 |
| **启动器自更新** | 下载新版启动器可执行文件并进行原地或临时重命名替换 | 不会删除或重置用户工作区数据 |

运行中的后端必须先在界面点击「停止」才能触发环境修复。**切勿在遇到环境报错时盲目直接删除整个安装目录或使用 `git reset --hard`**，应优先通过启动器内置的修复逻辑处理。

## 深入环境修复：安全重建机制

启动器内置的运行时重建逻辑包含多重安全防护与恢复机制：

1. **工作区归属校验**：
   - 清理前必须严格比对目标工作区与启动器自身可执行文件的相对关系。
   - 在 macOS 下必须位于 `Contents/AzurPilot`；在 Windows/Linux 下必须为启动器二进制同级的工作区。若工作区路径不属于当前启动器，将直接拒绝执行清理，防止误伤宿主其他目录。
2. **运行时进程强制回收**：
   - 扫描系统进程表，查找可执行文件或当前工作目录位于工作区内部的残留进程并安全回收，解除文件句柄占用。
3. **重新下载与替换部署引导脚本（3.0.5 增强）**：
   - 修复时不再跳过已有非空脚本，而是直接从仓库 raw 源重新下载并原子替换清单中的全部 `deploy/**` 脚本及当前系统对应的模板（如 `config/deploy.template.yaml`），即使旧脚本损坏或版本过旧也能瞬间修复。
   - 用户自定义配置（如 `config/deploy.yaml`、用户参数 `config/user.json`）、自定义 Python 脚本及清单外文件严格受保护，不被覆盖。
   - 逐文件原子替换：下载并验证成功一个替换一个，失败时保留已成功替换的文件并安全报错，不会将工作区置于空状态。
4. **清理 uv 缓存**：
   - 调度内嵌 uv 执行 `uv cache clean`，清除损坏或不完整的依赖 wheel 缓存。
5. **虚拟环境重置**：
   - 递归清除 `.venv`（清理 Windows 文件只读属性，并配置最多 20 次重试机制），完成后自动重新自举 Python 3.14.3 与项目依赖。

## 导出诊断日志

遇到无法自行解决的问题时，可通过首页「导出日志」功能生成诊断信息：

- **非阻塞后台打包**：日志压缩在专用后台线程执行，扫描 `log/` 目录下符合条件的日志文件并打成 ZIP 压缩包，不会造成主界面卡顿。
- **反馈指引**：在 GitHub Issues 或社区群反馈时，请附带该日志 ZIP 文件、启动器发布版本号（如 3.0.6）、操作系统架构与错误复现步骤；单纯的报错弹窗截图往往缺少底层上下文。提交前请确认并移除可能包含的个人隐私数据。

## 卸载与数据迁移

- **Windows 安装程序版**：
  - 打开 Windows 系统「设置」→「应用」→「已安装的应用」，选择启动器并执行卸载。
  - 卸载向导首先通过 `taskkill` 安全停止运行中的启动器与 Python 进程。
  - **交互式数据保留提示**：向导会弹出对话框提示「是否保留本地数据和运行环境」。点击「是」保留安装目录下的配置、日志与 `.venv`，以便将来重新安装无缝继续使用；点击「否」则彻底删除整个安装目录与快捷方式。
- **便携版与 macOS / Linux 应用包**：
  - 退出启动器后，先将 `config/`（包含账号凭据与实例配置）和 `AzurPilot_Data_Backup/` 备份到安全位置。
  - 备份完成后直接删除应用目录或将 `.app` 移入废纸篓。

## 常见故障排查表

| 现象 | 排查方向与处置 |
| --- | --- |
| 更新下载触发 HTTP 429 | 下载源触发限流；启动器具备退避重试机制，也可在「设置」中手动切换至 GitHub 或 Cloudflare CDN |
| 启动报错缺少 `pyproject.toml` | 核心仓库目录未成功拉取或被误删；执行首页「环境修复」重新初始化 |
| 依赖安装报 SSL 或连接中断 | 在「设置」中切换 PyPI 镜像源；若为内嵌 uv 缓存损坏，执行环境修复清理缓存 |
| Node.js 下载超时或 SHA-256 校验失败 | 镜像源网络异常；在「设置」中切换 Node.js 下载源（淘宝镜像 / 南京大学 / 官方源），重试启动 |
| 引导脚本语法错误或版本过旧 | 3.0.5 起点击首页「环境修复」会强制重新下载并替换全部 `deploy/` 脚本及系统模板，解决旧脚本损坏问题 |
| WebUI 前端无法加载 | 检查 `frontend/` 静态构建产物；启动器会自动自举 Node.js 24 便携包并重试前端构建 |
| macOS 升级后提示损坏或配置丢失 | 检查应用是否位于 `/Applications`，使用 `xattr -dr com.apple.quarantine` 重新信任；确认 `Contents/AzurPilot` 内数据目录完整 |
| 退出启动器后模拟器被连带关闭 | Windows 下需确认后端与模拟器正常声明并启用了 Breakaway 机制；可在诊断日志中核对 Job Object 释放记录 |

参见[安装启动器](/launcher/user/install)、[首次启动](/launcher/user/first-run)与[后端进程生命周期](/launcher/developer/backend-lifecycle)。

## 3.0.7：独立连接错误窗口与托盘恢复

启动器 **3.0.7（2026-11-08）** 将后端连接错误改为独立系统窗口：

- 后端无法连接时，窗口显示错误原因，并提供「退出」和「重试连接」。
- 重试成功后自动返回 WebUI。
- 后端未恢复时关闭错误窗口，主窗口会收进系统托盘；后端异常退出时会发送系统通知。
- Windows 可通过通知或双击托盘图标重新唤起主窗口。
- 确认、错误和设置弹窗统一为 WinUI 3 风格。

出现连接错误时，先阅读窗口中的原因并使用「重试连接」。不要因为 WebUI 未显示就直接删除工作区或重装环境。

## 当前 main 分支：托盘菜单与页面右键菜单

以下交互已进入 `main` 源码，但提交晚于稳定版 **3.0.7（2026-11-08）**；3.0.7 安装包不包含这些提交，需等待后续版本发布。

### 系统托盘

- **Windows**：右键托盘图标打开 Fluent 自绘菜单，包含「启动器首页」「显示 / 隐藏」「退出」。菜单贴近指针弹出；失焦、按 Esc 或短时间内再次右键可收起。
- **macOS**：继续使用系统原生托盘菜单，点击菜单栏图标显示。
- **Linux**：当前源码不创建系统托盘图标。
- **Windows 左键 / 双击**：后端运行中打开 WebUI；后端未运行时返回启动器首页。

### 页面内右键菜单

启动器主页面拦截 WebView 默认菜单，改为跟随应用主题的 Fluent 菜单：

- 刷新始终可用；
- 复制仅在存在文本选区时启用；
- 粘贴、全选仅在输入框或文本域聚焦时启用；
- Esc、点击菜单外或窗口失焦会关闭菜单；
- 粘贴需要 WebView 剪贴板读取权限；权限被拒或读取失败时会放弃，不会强行读取。

键盘焦点使用清晰的彩虹外描边；启用减少动态效果时会跳过菜单入场动画。
