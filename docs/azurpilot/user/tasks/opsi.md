# 大型作战

::: danger 必须先通关大世界主线
**使用本页任何大世界自动化功能前，必须先在游戏内通关大世界主线。** 仅解锁入口、进入过大世界或完成部分海域，都不等于主线通关。这是游戏进度前置，AzurPilot 不会替你通关，也不保证自动识别账号进度。
:::

## 模块结构

WebUI 大世界分组包含 **16 个独立调度任务**，另有通用设置页和独立模拟器。名称相近的部分配置组是子功能，不是独立任务。

| 类型 | 页面 / 配置组 | 用途 |
| --- | --- | --- |
| 通用设置 | **OpsiGeneral** | 行动力购买、石油限制、维修、随机事件、日志、通知 |
| 独立模拟器 | **OpsiSimulator** | 收益估算，不进入调度队列，也不操作游戏 |
| 子配置 | **OpsiAshAssist、OpsiSmartExplore、OpsiTarget、OpsiCheckLeveling、OpsiFleetAutoChange、OpsiSirenBug、OpsiFleet、OpsiFleetFilter** | 由信标、智能调度、耄耋相接、侵蚀 1 练级等功能调用 |

## 开始前检查

1. **通关大世界主线**，确认普通海域和相关入口已解锁。
2. 游戏分辨率设为 **1280×720**、帧率设为 **60 FPS**。
3. 打开「大型作战 · 减少 TB 引导」和「自律时自动提交道具」；关闭「安全海域默认开启自律」。
4. 打开剧情自动播放并设为特快；关闭待机模式、重复角色获得提示、快速更换二次确认和展示结算角色。
5. 检查大世界舰队、潜艇支援、维修阈值和补给资源。任务运行期间不要手动操作游戏。

::: warning 潜艇支援
进入「大型作战 → 右上角雷达 → 指令模块 → 潜艇支援」，取消勾选「X 消耗时潜艇出击」，避免在非预期时机消耗支援次数。
:::

## 资源与阈值

| 资源 | 含义 | 调度注意事项 |
| --- | --- | --- |
| 行动力 AP | 自然恢复约每 600 秒 1 点，自然上限 200；可由港口或行动力箱补充 | 超过上限的自然恢复会浪费 |
| 当前行动力 C | 游戏内当前显示的行动力 | 当前可用量 |
| 调度行动力 P | 智能调度用于决策的口径 | 启用行动力箱时可计入箱内储备；仪表盘总量始终包含箱子 |
| 黄币 Y | 大世界海域与任务产出的货币 | 补给和黄币目标调度 |
| 紫币 | 隐秘海域、深渊等内容产出 | 大世界商店兑换，购买优先级应谨慎设置 |

常用保留值：**K** = 黄币保留线（OperationCoinsPreserve）；**R** = 补币后的回补增量（OperationCoinsReturnThreshold，负值按 0 处理）；**B** = 补黄币时保留的行动力（ActionPointPreserve，设为 0 时回退到耄耋相接保留值）；**L** = 侵蚀 1 练级行动力保留线（MinimumActionPointReserve）；**M** = 月末清理保留线。

## 16 个独立调度任务

| 任务 | 用途与主要配置 |
| --- | --- |
| **OpsiDaily** | 接取、完成每日任务并处理奖励；可配置跳过塞壬研究、保留任务海域 |
| **OpsiExplore** | 月度重置后逐区开荒至 100%；配置路线、海域顺序和行动力保留；要求主线通关 |
| **OpsiExploreCleanup** | 开荒 100% 后对普通海域额外补扫事件；使用独立月度断点 |
| **OpsiShop** | 遍历友方港口购买补给；配置预设筛选、自定义清单和停购日期 |
| **OpsiVoucher** | 白票商店兑换；通过 Filter 配置档案坐标、材料等商品优先级 |
| **OpsiObscure** | 使用并清理隐秘海域坐标；配置危险等级、强制运行、全图 / 雷达扫描与中断续接 |
| **OpsiAbyssal** | 逐层清理深渊坐标；配置舰队筛选、潜艇冷却和重启后续接 |
| **OpsiStronghold** | 多轮攻坚塞壬要塞；支持多舰队轮换、潜艇支援、维修和补给 |
| **OpsiArchive** | 处理已有档案坐标，再从白票商店购买新坐标；额外前置见下方 |
| **OpsiMonthBoss** | 完成当月仲裁者 / 月度 Boss；配置普通或普通 + 困难、适应性检查和舰队 |
| **OpsiAshBeacon** | 余烬信标战斗与支援请求；OpsiAshAssist 是子配置，不是独立任务 |
| **OpsiMeowfficerFarming** | 指定侵蚀等级海域刷取指挥喵收益；配置行动力保留、危险等级和目标海域 |
| **OpsiHazard1Leveling** | 侵蚀 1 海域持续练级；配置行动力 / 黄币保留、舰队和停止条件 |
| **OpsiScheduling** | 按黄币、行动力和月度状态代理耄耋相接、隐秘、深渊、要塞、侵蚀 1 等子任务 |
| **OpsiPreventActionPointOverflow** | 行动力接近自然上限时临时执行指定任务；配置触发上限、停止下限和代理目标 |
| **OpsiCrossMonth** | 月度重置前入场等待，重置后处理新周期每日、坐标和耄耋相接；默认在重置前 10 分钟窗口执行 |

### 档案坐标的额外前置

除通关大世界主线外，**OpsiArchive** 还要求完成相关模拟战与塞壬试验场内容。任务会先处理已持有的档案坐标，再从白票商店购买下一份；月度开荒正在运行时会主动延期。

## 通用设置与子功能

- **OpsiGeneral**：行动力购买次数、石油限制、舰队维修阈值、维修包、随机地图事件、日志和通知。
- **OpsiFleet / OpsiFleetFilter**：任务舰队、潜艇支援及多舰队优先级。
- **OpsiSirenBug**：塞壬研究启用状态、Resource / Enemy 模式和执行舰队。
- **OpsiTarget**：耄耋相接目标海域；多海域需启用循环驻留，无效、重复或港口海域会触发保护性停止。
- **OpsiCheckLeveling / OpsiFleetAutoChange**：练度检查与侵蚀 1 舰队轮换辅助项，不是独立调度任务。
- **OpsiAshAssist**：余烬信标支援子配置。
- **OpsiSmartExplore**：归属 OpsiScheduling，与独立 OpsiExplore 月度开荒互斥，只支持默认黄币目标模式。
- **OpsiSimulator**：根据配置与统计进行蒙特卡洛收益估算；它是分析工具，不会替你执行战斗。

## 智能调度

**OpsiScheduling 是决策循环，不只是定时任务。** 它读取行动力、黄币、月度进度和子任务状态，再决定下一轮操作：

1. 月度开荒未完成时，优先等待或推进开荒。
2. 检查本月港口行动力购买状态，并按配置尝试购买。
3. 行动力低于保留线时，尝试使用行动力箱或购买行动力。
4. 月末清理窗口内，在遵守行动力底线的前提下代理要塞、隐秘、深渊和耄耋相接。
5. 黄币低于目标时，代理补币任务，达到回补增量后回到行动力调度。
6. 其他时间按子任务开关和行动力条件安排练级及资源任务。

::: warning 避免两个调度入口争抢同一海域
由 **OpsiScheduling** 接管的子任务，应在智能调度页启用对应选项，并在子任务页配置参数；不要同时启用子任务自己的独立 Scheduler。
:::

## 推荐启用顺序

1. 通关主线，完成游戏设置和舰队配置。
2. 单独启用 **OpsiDaily**，验证导航、接取和结算流程。
3. 月初启用 **OpsiExplore** 至 100%；按需执行 **OpsiExploreCleanup**。
4. 配置商店、隐秘、深渊、要塞、月度 Boss 和耄耋相接。
5. 确认子任务参数与舰队筛选无误，再启用 **OpsiScheduling**。
6. 需要时再启用 **OpsiPreventActionPointOverflow** 和 **OpsiCrossMonth**。

初次配置不要一次性打开全部任务。先单项运行、检查日志与海域状态，再交给智能调度。

## 安全边界与排查

- **OpsiObscure、OpsiAbyssal、OpsiCrossMonth** 默认按敏感任务处理。异常时实例会停止，而不是自动重启游戏继续执行。
- 开荒、跨月和坐标清理期间不要手动操作游戏，也不要让其他工具同时控制同一模拟器。
- 侵蚀 1 练级会持续消耗行动力；修改保留线、舰队或停止条件前，先观察一轮资源收支。
- 行动力不足、无法购买或没有可执行坐标时，延期或停止可能是预期行为，不要直接关闭保护选项。

| 现象 | 排查方向 |
| --- | --- |
| 无法进入海域或开荒不推进 | 确认主线已通关，再检查海域解锁、核心版本和识别资源 |
| 行动力不足后停止 | 检查 P / C、行动力箱、L / B 保留线和购买权限 |
| 黄币达不到目标 | 检查 K + R、补币任务、舰队和可执行坐标 |
| 开荒进度没有保存 | 确认海域是否正常退出 |
| 智能调度没有接管 | 检查 OpsiScheduling、子任务开关和月度开荒状态 |
| 档案坐标不运行 | 检查主线、模拟战、塞壬试验场及可用坐标 / 白票 |
| 敏感任务报错后停止 | 查看错误日志和截图，确认状态后手动恢复 |

更多游戏前置设置见[环境与兼容性](/guide/requirements)，调度规则见[调度器与任务编排](/azurpilot/user/scheduler)。
