# 任务总览

核心程序的每个可调度功能都对应一个**任务命令**。命令是英文标识（如 `OpsiHazard1Leveling`），WebUI 里显示的是中文名（如「侵蚀1练级」）。

下表由 `module/config/argument/args.json`、`module/config/i18n/zh-CN.json` 与 `task.yaml` 在构建期生成，可以直接搜索。

## <DocIcon name="clipboard" /> 每个任务的通用结构

所有任务共享同一套调度字段，位于任务页顶部的「调度设置」：

| 字段 | 含义 | 默认 |
| --- | --- | --- |
| 启用该功能 | 加入调度队列 | 关 |
| 推送通知 | 任务结束推送结果 | 关 |
| 下一次运行时间 | 到期即运行 | 2020-01-01（立即） |
| 运行成功后推迟 | 下次间隔（分钟） | 任务自定义 |
| 运行失败后推迟 | 失败间隔（分钟） | 120 |
| 服务器刷新时间 | 每日基准 | 00:00 |
| 敏感任务 | 出错停止而非重启 | 部分大世界任务开启 |

除此之外，每个任务还有自己的参数组。手册里只讲**会影响结果**的字段，其余保持默认即可。

## <DocIcon name="eye" /> 怎么读一个任务页

以「科研」为例，推荐按这个顺序：

1. **用途**：它替你点哪些按钮、产出什么。
2. **前置条件**：需要解锁什么、需要多少队列、是否消耗石油。
3. **关键配置**：选项目、队列策略、是否用钻石加速。
4. **推荐配置**：一组可以直接抄的值。
5. **验证**：跑完后看哪里确认成功。
6. **限制**：哪些版本/服务器不适用。

## <DocIcon name="lightbulb" /> 保守起步建议

新账号或刚接手的环境，建议只开这些：

```text
Restart           # 每日重启，清理内存
Reward            # 一键收获
Commission        # 委托
Research          # 科研
Dorm              # 后宅
Daily             # 每日任务
```

稳定运行几天、确认日志无反复失败后，再逐步加入出击、活动、大世界。大世界与活动是配置复杂度最高的两块，不要和初次安装同一天做。
