# 控制台、統計、懸浮窗與熒幕保護

Android 宿主把「控制」和「顯示」分開了：控制台負責配置，懸浮窗負責隨手操作，熒幕保護負責在不看熒幕時省電與防燒屏。

![Android 設定頁（深色）](/img/android-settings-dark.jpg)

<Figure caption="設定頁：外觀、下載源、權限、保活與熒幕保護開關。截圖來自 Android 倉庫。" />

| 頁面 | 內容 |
| --- | --- |
| 主頁 | Runtime 狀態、部署進度、啟動/停止、遠程綁定入口 |
| 運行控制 | 虛擬熒幕畫面、實例選擇、任務開始/停止 |
| 控制台 | 內嵌 WebUI（與桌面版同一前端） |
| 統計 | 原生八類報表、資源管理與 CSV 匯出 |
| 日誌 | 宿主 / Runtime / 特權服務三路日誌 |
| 設定 | 外觀、下載源、運行與安全、保活、熒幕保護、關於 |

主頁右上角的綁定按鈕可以直接進入遠程 AP 配對，不需要先部署本機 Runtime。

## 原生統計與資源管理

在 AzurPilot 頁面的「總覽」中開啟「統計」，即可進入 Android 原生統計模組。報表按目前選取的 Runtime 實例分開；相應任務尚未執行時，該類別可能暫時沒有資料。

### 八類報表

| 分類 | 內容 |
| --- | --- |
| 資源趨勢 | 資源數量與變化趨勢 |
| 大世界趨勢 | 大世界行動相關趨勢 |
| 大世界總結 | 大世界資源與任務彙總 |
| 委託收益 | 委託獎勵統計 |
| 艦船經驗 | 艦船經驗產出 |
| 大世界掉落 | 大世界掉落物統計，可按任務篩選 |
| 科研掉落 | 科研掉落統計，可按期數或心智 / 物資視圖查看 |
| 倉庫物品 | 倉庫物品統計，可主動執行倉庫統計任務 |

報表按類別提供指標卡、趨勢曲線、表格和備註。趨勢範圍可選 1、7、30、90 或 365 天；大世界報表可按月份查看，科研報表可按期數或心智 / 物資切換，大世界掉落支援按任務篩選。「重新統計」只會重新彙總本機已記錄的領取資料，不會再次操作遊戲。報表可匯出 CSV。

### 資源管理

可選 1、7、30 天或自訂日期範圍（最長 366 天），並按資源和任務篩選。頁面包含庫存彙總、資源流向圖和流水明細；庫存彙總會分開顯示目前庫存、區間收入、支出和校準，校準不計入任務收支。流水會標示已確認、實測、識別或校準等依據，並可匯出 CSV。

石油控制可獨立啟用，目標值範圍為 1000–24999。目前庫存取自最近一次有效庫存快照；沒有快照時會留空，不代表庫存為 0。

「倉庫物品」中的「執行倉庫統計」會啟動 `StorageStatistics` 採集任務。重新整理報表只會讀取最近一次完整快照，不會自動重新掃描。

::: warning 發佈狀態
原生統計模組已進入 Android `main`（提交 `7b468fb7`）。截至 2026-11-12，最新公開滾動 APK 仍為 `1.3.196`（2026-11-08），早於該提交；請勿據此認定 `1.3.196` 已包含這些頁面。
:::

## <DocIcon name="monitor" /> 懸浮窗

基於 FloatingX 的全局浮窗，在任意應用或桌面之上可用：

| 操作 | 效果 |
| --- | --- |
| 單擊 | 展開/收起面板 |
| 啟動 / 停止 | 控制當前實例 |
| 隊列 | 查看調度隊列與當前任務 |
| 切換實例 | 在多實例間切換目標 |
| 日誌 | 實時滾動最近的運行日誌 |

懸浮窗是獨立 Window，讀不到 Activity 的 `Configuration` 或 `ViewModelStore`。它通過 `AppThemeState` 與 `OverlayController` 獲取狀態，所以主題切換後浮窗會跟着變，但不會共享頁面的臨時狀態。

::: tip 懸浮窗不顯示
檢查「懸浮窗」權限是否授予。部分廠商 ROM 還有單獨的「後台彈出介面」開關。
:::

## <DocIcon name="eye" /> 熒幕保護（防燒屏）

後台運行時熒幕長期點亮，OLED 設備有燒屏風險。熒幕保護提供：

| 行為 | 參數 |
| --- | --- |
| 背景 | 黑色低亮度 |
| 進入方式 | 手動開啟，或任務啟動時自動進入 |
| 漂移 | 無操作 30 秒後，每 10 秒上下移動 16dp |
| 退出 | 向右拖動解鎖條到末端並鬆手 |

漂移是週期性小幅位移，不會影響遊戲畫面（熒幕保護覆蓋在虛擬熒幕之上，遊戲仍在後台運行）。LCD 設備同樣可用，只是收益不如 OLED 明顯。

## <DocIcon name="box" /> 桌面小組件

支援 Glance / RemoteViews 小組件，可顯示運行狀態並快速啟停。

部分舊版廠商系統不能可靠解析 `?attr` 矢量着色與 `cornerRadius`，因此小組件使用顯式 drawable 資源，不依賴主題屬性。

## <DocIcon name="zap" /> 保活

後台運行最容易受到系統省電策略影響。宿主提供三層：

1. **前台服務**：Runtime 或虛擬熒幕活躍時保進程，通知欄常駐。
2. **多路徑保活**：`KeepAliveManager` 按設定啟用多條路徑，可重複啟停，設定開關是最終裁決。
3. **電池優化白名單**：需要你手動授權。

建議同時設定：

- 系統設定 → 電池 → 應用 → AzurPilot → 不受限制。
- 廠商的「自啟動」「後台運行」白名單。
- 關閉「省電模式」對後台的限制。

::: warning 保活不是萬能的
部分 ROM 會在極端省電或記憶體壓力下強殺進程。這時任務會中斷，Runtime 需要重新啟動。把日誌匯出後能看出是被系統殺死還是自身崩潰。
:::

## <DocIcon name="scroll" /> 日誌

三路日誌分開歸檔：

| 日誌 | 位置 | 內容 |
| --- | --- | --- |
| 宿主日誌 | 應用私有目錄 | Compose、網關、部署、更新 |
| Runtime 日誌 | `proot/session.log` + 上游 `log/` | 調度器與業務 |
| 特權啟動鏈 | 獨立時間線 | ADB 啟動、Binder 回投、虛擬熒幕 |

特性：

- 異常時自動儲存當前畫面快照。
- 預設 7 天輪轉，過期清理。
- 一鍵打包匯出為 zip。

匯出前確認壓縮包裏沒有 `config/deploy.yaml`、`password.txt`、`remote-access.json`。這些檔案在 Runtime 的 `config/` 下，匯出日誌時不會自動包含，但手動打包整個目錄時會。

## 提交機型兼容性報告

在「設定 → 提交你的機型」檢查自動採集的機型、系統與運行模式資訊，**親自選擇「可正常使用」或「無法正常使用」**，同意公開到 GitHub 後提交。報告會作為評論追加到 [Android 機型支援 Issue #1](https://github.com/wess09/AzurPilot-for-Android/issues/1)，不會新建 Issue。重複報告會關聯已有評論；未明確選擇實際結果時提交按鈕禁用，伺服端也會直接拒絕未經實際驗證的提交。

該功能嚴格去敏，不收集 IMEI、序列號、Android ID、MAC、電話狀態、日誌或截圖；提交前仍請在介面上核對顯示的資訊。

### 提交網絡與憑據説明

- **公網 API 地址**：提交請求發送至部署於騰訊雲 Docker 服務的 `https://afa-api.azurpilot.com/v1/device-reports`。
- **正文簽名防護**：客戶端使用內置私鑰對請求進行 SHA256withRSA 簽名（攜帶 5 分鐘有效期時間戳與 32 字符隨機 nonce 防重放）。
- **憑據要求**：簽名憑據由 GitHub Actions 在構建發佈版時注入（`AZURPILOT_DEVICE_REPORT_*`）。本地自行編譯的未注入憑據 Debug 包在打開此頁面時會提示功能不可用，屬正常現象。
- **真機驗證邊界**：靜態代碼與單元測試僅驗證數據採集與格式去敏；真實的評論提交依賴伺服端線上與 GitHub API 連通，請確保在聯網且測試過核心功能後再行提交。

詳細字段規範、去敏規則與伺服端 Docker 部署見[設備上報技術文檔](https://github.com/wess09/AzurPilot-for-Android/blob/main/doc/device-reporting.md)；Android Runtime 工作原理見[開發文檔](/zh-HK/android/developer/runtime)。

## <DocIcon name="message" /> 常見問題

| 現象 | 原因 |
| --- | --- |
| 浮窗點擊無反應 | 懸浮窗權限被回收，或省電策略限制後台 |
| 熒幕保護不漂移 | 系統關閉了動畫（開發者選項），或處於省電模式 |
| 小組件顯示舊狀態 | 啟動器快取，重新添加小組件 |
| 息屏後任務停止 | 電池優化未放行 |
| 日誌匯出為空 | 日誌已輪轉清理，或匯出目錄無權限 |
