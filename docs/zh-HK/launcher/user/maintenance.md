# 更新、修復與移除

**啟動器版本、核心程序提交和運行組件版本彼此獨立。** 更新啟動器二進制不會自動重裝所有 Git/ADB、Python 運行時或重置核心代碼；修改核心提交也不代表桌面啟動器必須同步升級。在源碼倉庫中，啟動器配置基線統一採用 `0.0.0` 模板，發佈版則由 CI 自動注入諸如 **3.0.4** 的 Semantic Version。

## 檢查與切換版本

啟動器支援雙更新通道與靈活的鏡像源配置：

- **版本通道**：在「設定」中選擇 `stable`（正式版，預設）或 `canary`（測試構建）。發現新版本時首頁會自動彈出更新提示，並避免同一版本重複騷擾。若當前通道沒有更新版本，則保持靜默。
- **更新下載源**：可選自動（`auto`，預設）、官方源（`official`）、GitHub、Cloudflare CDN。自動模式會綜合系統原始中文語言與當前時區優先選擇最快節點，網絡失敗時自動按備選順序退避回退。
- **載荷完整性與安全**：所有更新載荷均需通過 SHA-256 哈希校驗；在非 GitHub 官方源拉取二進制時可使用編譯期綁定的 mTLS 客戶端身份驗證。更新過程若被用戶取消或中斷，將完整保留舊版本，絕不替換為不完整的損壞檔案。

「設定」面板還提供獨立配置項：組件下載源、Python 與 PyPI 鏡像、介面語言（簡中/繁中/日/英）、背景音樂開關、減弱動態效果（暫停背景動畫/視頻）以及阻止計算機空閒自動睡眠。

## 部署、啟動與環境修復的區別

| 操作類別 | 具體執行動作 | 用戶數據與配置影響 |
| --- | --- | --- |
| **部署組件** | 讀取清單並下載 Git、ADB 及引導腳本到指定目錄 | 僅準備外部工具，不影響核心代碼與配置 |
| **啟動運行** | 檢測/複用獨立 Python 3.14.3、更新倉庫、`uv sync` 鎖定依賴、啟動後端 | 完整沿用已有資料庫與 `config/` 配置 |
| **環境修復** | 停止進程、清理 uv 快取並徹底重建 `.venv` 虛擬環境 | **嚴格保留**核心代碼、`config/` 與 `log/` |
| **啟動器自更新** | 下載新版啟動器可執行檔案並進行原地或臨時重命名替換 | 不會刪除或重置用戶工作區數據 |

運行中的後端必須先在介面點擊「停止」才能觸發環境修復。**切勿在遇到環境報錯時盲目直接刪除整個安裝目錄或使用 `git reset --hard`**，應優先通過啟動器內置的修復邏輯處理。

## 深入環境修復：安全重建機制

啟動器內置的運行時重建邏輯（`cleanup_runtime_for_rebuild`）包含多重安全防護機制：

1. **工作區歸屬校驗**：
   - 清理前必須嚴格比對目標工作區與啟動器自身可執行檔案的相對關係。
   - 在 macOS 下必須位於 `Contents/NTEPilot`（或 `AzurPilot`）；在 Windows/Linux 下必須為啟動器二進制同級的工作區。若工作區路徑不屬於當前啟動器，將直接拒絕執行清理，防止誤傷宿主其他目錄。
2. **運行時進程強制回收**：
   - 掃描系統進程表，查找可執行檔案或當前工作目錄位於工作區內部的殘留進程並安全回收，解除檔案句柄佔用。
3. **清理 uv 快取**：
   - 調度內嵌 uv 執行 `uv cache clean`，清除損壞或不完整的依賴 wheel 快取。
4. **虛擬環境重置**：
   - 遞歸清除 `.venv`（清理 Windows 檔案只讀屬性，並配置最多 20 次重試機制），完成後自動重新自舉 Python 3.14.3 與項目依賴。

## 匯出診斷日誌

遇到無法自行解決的問題時，可通過首頁「匯出日誌」功能生成診斷資訊：

- **非阻塞後台打包**：日誌壓縮在專用後台執行緒執行，掃描 `log/` 目錄下符合條件的日誌檔案並打成 ZIP 壓縮包，不會造成主介面卡頓。
- **反饋指引**：在 GitHub Issues 或社區羣反饋時，請附帶該日誌 ZIP 檔案、啟動器發佈版本號（如 3.0.4）、操作系統架構與錯誤復現步驟；單純的報錯彈出視窗截圖往往缺少底層上下文。提交前請確認並移除可能包含的個人隱私數據。

## 移除與數據遷移

- **Windows 安裝程序版**：
  - 打開 Windows 系統「設定」→「應用」→「已安裝的應用」，選擇啟動器並執行移除。
  - 移除嚮導首先通過 `taskkill` 安全停止運行中的啟動器與 Python 進程。
  - **交互式數據保留提示**：嚮導會彈出對話框提示「是否保留本地數據和運行環境」。點擊「是」保留安裝目錄下的配置、日誌與 `.venv`，以便將來重新安裝無縫繼續使用；點擊「否」則徹底刪除整個安裝目錄與快捷方式。
- **便攜版與 macOS / Linux 應用包**：
  - 退出啟動器後，先將 `config/`（包含帳號憑據與實例配置）和 `AzurPilot_Data_Backup/` 備份到安全位置。
  - 備份完成後直接刪除應用目錄或將 `.app` 移入廢紙簍。

## 常見疑難排解表

| 現象 | 疑難排解方向與處置 |
| --- | --- |
| 更新下載觸發 HTTP 429 | 下載源觸發限流；啟動器具備退避重試機制，也可在「設定」中手動切換至 GitHub 或 Cloudflare CDN |
| 啟動報錯缺少 `pyproject.toml` | 核心倉庫目錄未成功拉取或被誤刪；執行首頁「環境修復」重新初始化 |
| 依賴安裝報 SSL 或連接中斷 | 在「設定」中切換 PyPI 鏡像源；若為內嵌 uv 快取損壞，執行環境修復清理快取 |
| WebUI 前端無法加載 | 檢查 `frontend/` 靜態構建產物；查看日誌中是否提示缺少 Node.js 運行時 |
| macOS 升級後提示損壞或配置丟失 | 檢查應用是否位於 `/Applications`，使用 `xattr -dr com.apple.quarantine` 重新信任；確認 `Contents/` 內數據目錄完整 |
| 退出啟動器後模擬器被連帶關閉 | Windows 下需確認後端與模擬器正常聲明並啟用了 Breakaway 機制；可在診斷日誌中核對 Job Object 釋放記錄 |

## Node.js 下載源（正式版 3.0.6）

正式版 **3.0.6** 已恢復缺少 Node.js 執行時的自動下載與安裝。Node.js 下載源獨立於 Git、Python 和 PyPI 鏡像，可選「自動／淘寶鏡像／南京大學／官方」，下載失敗會嘗試備選源並以官方 SHA-256 校驗。首次啟動失敗時，請在設定中切換 Node.js 下載源後重試「啟動」或「環境修復」，不要刪除 `config/` 與日誌。原始碼模板的 `0.0.0` 不等於正式發佈版號。


## 3.0.7：獨立連線錯誤視窗與系統匣復原

啟動器 **3.0.7（2026-11-08）** 將後端連線錯誤改為獨立系統視窗：

- 後端無法連線時，視窗顯示錯誤原因，並提供「退出」及「重新連線」。
- 重新連線成功後自動返回 WebUI。
- 後端未恢復時關閉錯誤視窗，主視窗會收進系統匣；後端意外退出時亦會發送系統通知。
- Windows 可透過通知或雙擊系統匣圖示重新叫出主視窗。
- 確認、錯誤及設定彈窗統一為 WinUI 3 風格。

出現連線錯誤時，先閱讀視窗中的原因並使用「重新連線」。不要只因 WebUI 未顯示便刪除工作區或重新安裝環境。

## 目前 main 分支：托盤選單與頁面右鍵選單

以下互動已進入 `main` 原始碼，但提交時間晚於穩定版 **3.0.7（2026-11-08）**；3.0.7 安裝包不包含這些提交，需等待後續版本發佈。

### 系統托盤

- **Windows**：右鍵托盤圖示會開啟 Fluent 自繪選單，包含「啟動器首頁」「顯示 / 隱藏」「退出」。選單貼近指標彈出；失焦、按 Esc 或短時間內再次右鍵即可收起。
- **macOS**：繼續使用系統原生托盤選單，點擊選單列圖示顯示。
- **Linux**：目前原始碼不會建立系統托盤圖示。
- **Windows 左鍵 / 雙擊**：後端運行中開啟 WebUI；後端未運行時返回啟動器首頁。

### 頁面內右鍵選單

啟動器主頁會攔截 WebView 預設選單，改為跟隨應用主題的 Fluent 選單：

- 重新整理始終可用；
- 複製只會在有文字選取時啟用；
- 貼上、全選只會在輸入框或文字區域取得焦點時啟用；
- Esc、點擊選單外或視窗失焦會關閉選單；
- 貼上需要 WebView 剪貼簿讀取權限；權限被拒或讀取失敗時會放棄，不會強行讀取。

鍵盤焦點使用清晰的彩虹外描邊；啟用減少動態效果時會略過選單入場動畫。
