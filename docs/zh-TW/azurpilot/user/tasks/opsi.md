# 大型作戰

::: danger 必須先通關大世界主線
**使用本頁任何大世界自動化功能前，必須先在遊戲內通關大世界主線。** 只解鎖入口、曾經進入大世界或完成部分海域，都不代表主線已通關。這是遊戲進度前置，AzurPilot 不會代替玩家完成主線，也不保證自動判定帳號進度。
:::

## 模組結構

WebUI 大世界分組包含 **16 個獨立排程任務**，另有通用設定頁和獨立模擬器。部分名稱相近的設定組屬於子功能，並非獨立任務。

| 類型 | 頁面 / 設定組 | 用途 |
| --- | --- | --- |
| 通用設定 | **OpsiGeneral** | 行動力購買、石油限制、維修、隨機事件、日誌、通知 |
| 獨立模擬器 | **OpsiSimulator** | 收益估算，不加入排程，也不會操作遊戲 |
| 子設定 | **OpsiAshAssist、OpsiSmartExplore、OpsiTarget、OpsiCheckLeveling、OpsiFleetAutoChange、OpsiSirenBug、OpsiFleet、OpsiFleetFilter** | 由信標、智能排程、耄耋相接、侵蝕 1 練級等功能呼叫 |

## 開始前檢查

1. **通關大世界主線**，確認普通海域和相關入口已解鎖。
2. 遊戲解析度設為 **1280×720**、幀率設為 **60 FPS**。
3. 開啟「大型作戰 · 減少 TB 引導」和「自律時自動提交道具」；關閉「安全海域預設開啟自律」。
4. 開啟劇情自動播放並設為特快；關閉待機模式、重複角色獲得提示、快速更換二次確認和展示結算角色。
5. 檢查大世界艦隊、潛艇支援、維修門檻和補給資源。任務執行期間不要手動操作遊戲。

::: warning 潛艇支援
進入「大型作戰 → 右上角雷達 → 指令模組 → 潛艇支援」，取消勾選「X 消耗時潛艇出擊」，避免在非預期時機消耗支援次數。
:::

## 資源與門檻

| 資源 | 含義 |
| --- | --- |
| AP | 約每 600 秒自然恢復 1 點，自然上限 200 |
| C | 遊戲內目前顯示的行動力 |
| P | 智能排程用來決策的行動力口徑；啟用行動力箱時可計入箱內儲備 |
| Y | 大世界黃幣 |
| 紫幣 | 隱秘海域、深淵等內容產出，用於大世界商店 |

常用保留值：**K** = 黃幣保留線（OperationCoinsPreserve）；**R** = 補幣後回補增量（OperationCoinsReturnThreshold，負數按 0）；**B** = 補黃幣時保留的行動力（ActionPointPreserve，0 會回退到耄耋相接保留值）；**L** = 侵蝕 1 練級行動力保留線；**M** = 月末清理保留線。儀表板 AP 總量始終包含行動力箱。

## 16 個獨立排程任務

| 任務 | 用途與主要設定 |
| --- | --- |
| **OpsiDaily** | 完成每日任務及獎勵；可設定跳過塞壬研究、保留任務海域 |
| **OpsiExplore** | 月度重置後逐區開荒至 100%；設定路線、海域順序、行動力保留；要求主線通關 |
| **OpsiExploreCleanup** | 開荒 100% 後對普通海域額外補掃事件；使用獨立月度斷點 |
| **OpsiShop** | 巡迴友方港口購買補給；設定預設篩選、自訂清單和停購日期 |
| **OpsiVoucher** | 白票商店兌換；透過 Filter 設定檔案座標和材料優先級 |
| **OpsiObscure** | 使用並清理隱秘海域座標；設定危險等級、強制執行、全圖 / 雷達掃描和中斷續接 |
| **OpsiAbyssal** | 逐層清理深淵座標；設定艦隊篩選、潛艇冷卻及重啟後續接 |
| **OpsiStronghold** | 多輪攻堅塞壬要塞；支援多艦隊輪換、潛艇支援、維修及補給 |
| **OpsiArchive** | 處理已有檔案座標，再從白票商店購買新座標；額外前置見下方 |
| **OpsiMonthBoss** | 完成當月仲裁者 / 月度 Boss；設定普通或普通 + 困難、適應性檢查和艦隊 |
| **OpsiAshBeacon** | 餘燼信標戰鬥與支援請求；OpsiAshAssist 是子設定，不是獨立任務 |
| **OpsiMeowfficerFarming** | 指定侵蝕等級海域刷取指揮喵收益；設定行動力保留、危險等級和目標海域 |
| **OpsiHazard1Leveling** | 侵蝕 1 海域持續練級；設定行動力 / 黃幣保留、艦隊和停止條件 |
| **OpsiScheduling** | 按黃幣、行動力和月度狀態代理耄耋相接、隱秘、深淵、要塞、侵蝕 1 等子任務 |
| **OpsiPreventActionPointOverflow** | 行動力接近自然上限時臨時執行指定任務；設定觸發上限、停止下限和代理目標 |
| **OpsiCrossMonth** | 月度重置前入場等待，重置後處理新週期每日及座標；預設在重置前 10 分鐘窗口執行 |

### 檔案座標的額外前置

除通關大世界主線外，**OpsiArchive** 還要求完成相關模擬戰與塞壬試驗場內容。任務先處理已持有的檔案座標，再從白票商店購買下一份；月度開荒正在執行時會主動延期。

## 通用設定與子功能

- **OpsiGeneral**：行動力購買次數、石油限制、艦隊維修門檻、維修包、隨機事件、日誌和通知。
- **OpsiFleet / OpsiFleetFilter**：任務艦隊、潛艇支援及多艦隊優先級。
- **OpsiSirenBug**：塞壬研究啟用狀態、Resource / Enemy 模式和執行艦隊。
- **OpsiTarget**：耄耋相接目標海域；多海域需啟用循環駐留，無效、重複或港口海域會觸發保護性停止。
- **OpsiCheckLeveling / OpsiFleetAutoChange**：練度檢查和侵蝕 1 艦隊輪換輔助，不是獨立任務。
- **OpsiAshAssist**：餘燼信標支援子設定。
- **OpsiSmartExplore**：屬於 OpsiScheduling，與獨立 OpsiExplore 月度開荒互斥，只支援預設黃幣目標模式。
- **OpsiSimulator**：根據設定和統計進行蒙地卡羅收益估算；它是分析工具，不會替你執行戰鬥。

## 智能排程

**OpsiScheduling 是決策循環，不只是定時任務。** 它讀取行動力、黃幣、月度進度和子任務狀態，再決定下一輪操作：

1. 月度開荒未完成時，優先等待或推進開荒。
2. 檢查本月港口行動力購買狀態，並按設定嘗試購買。
3. 行動力低於保留線時，嘗試使用行動力箱或購買行動力。
4. 月末清理窗口內，在遵守行動力底線的前提下代理要塞、隱秘、深淵和耄耋相接。
5. 黃幣低於目標時，代理補幣任務，達到回補增量後回到行動力排程。
6. 其他時間按子任務開關和行動力條件安排練級及資源任務。

::: warning 避免兩個排程入口爭搶同一海域
由 **OpsiScheduling** 接管的子任務，應在智能排程頁啟用對應選項，並在子任務頁設定參數；不要同時啟用子任務自己的獨立 Scheduler。
:::

## 建議啟用順序

1. 通關主線，完成遊戲設定和艦隊配置。
2. 單獨啟用 **OpsiDaily**，驗證導航、接取和結算流程。
3. 月初啟用 **OpsiExplore** 至 100%；按需執行 **OpsiExploreCleanup**。
4. 設定商店、隱秘、深淵、要塞、月度 Boss 和耄耋相接。
5. 確認子任務參數與艦隊篩選無誤，再啟用 **OpsiScheduling**。
6. 有需要才啟用 **OpsiPreventActionPointOverflow** 和 **OpsiCrossMonth**。

初次設定不要一次開啟全部任務。先單項執行、檢查日誌與海域狀態，再交給智能排程。

## 安全邊界與排查

- **OpsiObscure、OpsiAbyssal、OpsiCrossMonth** 預設按敏感任務處理。異常時實例會停止，而不是自動重啟遊戲繼續執行。
- 開荒、跨月和座標清理期間不要手動操作遊戲，也不要讓其他工具同時控制同一模擬器。
- 侵蝕 1 練級會持續消耗行動力；修改保留線、艦隊或停止條件前，先觀察一輪資源收支。
- 行動力不足、無法購買或沒有可執行座標時，延期或停止可能是預期行為，不要直接關閉保護選項。

| 現象 | 排查方向 |
| --- | --- |
| 無法進入海域或開荒不推進 | 確認主線已通關，再檢查海域解鎖、核心版本和識別資源 |
| 行動力不足後停止 | 檢查 P / C、行動力箱、L / B 保留線和購買權限 |
| 黃幣達不到目標 | 檢查 K + R、補幣任務、艦隊和可執行座標 |
| 開荒進度沒有保存 | 確認海域是否正常退出 |
| 智能排程沒有接管 | 檢查 OpsiScheduling、子任務開關和月度開荒狀態 |
| 檔案座標不運行 | 檢查主線、模擬戰、塞壬試驗場及可用座標 / 白票 |
| 敏感任務報錯後停止 | 查看錯誤日誌和截圖，確認狀態後手動恢復 |
