# 実行方式の選択

AzurPilot には3つの利用ルートが存在しますが、実行されるのは**すべて同一のコアプログラム**です。違いは「誰が Python 環境を用意し、誰がバックエンドプロセスをホストし、ゲームがどこで動作するか」という点にあります。

| 実行方式 | ゲームの動作環境 | PCの常時起動 | 適用シナリオ |
| --- | --- | --- | --- |
| デスクトップランチャー | Windows / macOS / Linux 上のエミュレーター | 必要 | 長時間放置、多重起動、最高パフォーマンス |
| Android ローカル実行 | スマートフォン上のゲームクライアント | 不要 | 常時起動PCがない、または旧端末を周回専用にしたい場合 |
| ソースコード実行 | Python 3.14 をサポートする任意の環境 | 必要 | 開発、デバッグ、カスタム改変 |
| リモートクライアント | 他のマシン上のインスタンス | 不要（端末側） | 自宅PC上のインスタンスをスマートフォンで確認・制御 |

## <DocIcon name="info" /> 事前に確認すべき3つの質問

<DocIcon name="smartphone" /> **1. ゲームをどこで動作させますか？**
エミュレーター（MuMu、LDPlayer、BlueStacks、NoxPlayer 等）はデスクトップルートに適しています。スマートフォンのローカル実行には Android 9.0 以上、ARM64 または x86_64、4GB 以上のメモリ、2.5GB 以上の空きストレージが必要です。

<DocIcon name="clock" /> **2. そのマシンを常時起動できますか？**
スケジューラーの設計目標は 24時間365日の連続稼働です。PC を毎晩シャットダウンする場合でも次回起動時にタスクは再開されますが、大世界（オペレーション・サイレン）や委託など時間経過を伴うコンテンツの収益効率は低下します。

<DocIcon name="wrench" /> **3. コマンドラインの操作を厭いませんか？**
コマンドラインを避けたい場合 → ランチャーまたは APK を選択してください。操作に問題がない、またはコードの改変が必要な場合 → ソースコード実行を選択してください。詳細は[開発者ポータル](/ja/azurpilot/developer/)を参照してください。

## <DocIcon name="compass" /> 3つのルートの具体的な導入手順

<div class="ap-grid ap-grid--3">
<div>

#### デスクトップランチャー
圧縮ファイルをダウンロードし、展開して実行します。ランチャーが自動的に `.venv` を構築し、コードを取得して依存関係を同期し、WebUI を開きます。
[ランチャーのインストール →](/ja/launcher/user/install)
</div>
<div>

#### Android ホスト
APK をインストールし、Runtime の展開を待機した上で、ADB または Root をアクティベートし、アプリ内でインスタンスを設定します。
[Android 版のインストール →](/ja/android/user/install)
</div>
<div>

#### ソースコード実行
Python 3.14 と uv が必要です。`uv sync --frozen` を実行した後に `gui.py` を起動します。開発およびトラブルシューティングに適しています。
[ソースコード実行 →](/ja/guide/install#源码运行)
</div>
</div>

## <DocIcon name="clipboard" /> いずれのルートでも必須となる3つの前提

1. <DocIcon name="settings" /> **ゲーム内設定**は推奨値に合わせて調整する必要があります。設定が正しくない場合、画像認識に失敗します。設定項目の一覧は[動作環境と互換性](/ja/guide/requirements#ゲーム内設定)を参照してください。
2. <DocIcon name="monitor" /> **スクリーンショット解像度は 1280×720 固定**です。これは画像認識リソースの制作基準であり、UI の表示サイズではありません。
3. <DocIcon name="cloud" /> **初回実行時はインターネット接続が必須**です。ランチャーでの Python および依存関係の取得、Android 軽量版での Runtime の取得、コアプログラムのコード取得などに必要となります。

::: warning アカウントの自己責任原則
自動化操作はゲームの利用規約に抵触するため、アカウント停止のリスクが存在します。AzurPilot はいかなる検知回避機能も提供せず、アカウントに対する責任を負いません。検証されていない高リスクな操作をメインアカウントで実行することは推奨されません。
:::
