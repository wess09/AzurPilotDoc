::: warning Linux でのランチャー依存関係
ランチャーの実行には `libwebkit2gtk-4.1` および比較的新しい glibc が必要です（CI ビルドは Ubuntu 22.04 を使用）。ディストリビューションが古くランチャーが起動しない場合でも、コアプログラム単体であればコマンドラインから起動可能です。
:::

## <DocIcon name="monitor" /> エミュレーター

コアプログラムは ADB を経由してエミュレーターに接続します。以下は設定内にプリセットされているデフォルトの Serial です。「エミュレーター Serial」にそのまま入力して使用できます：

| エミュレーター | デフォルト Serial | 備考 |
| --- | --- | --- |
| MuMu Player 12 | `127.0.0.1:16384` | 多重起動時はポート番号がインクリメント |
| MuMu Player / MuMu X | `127.0.0.1:7555` | — |
| MuMu Pro（macOS） | `127.0.0.1:16384` | 多重起動時は 16416, 16448... |
| LDPlayer（雷電） | `emulator-5554` または `127.0.0.1:5555` | 専用スクリーンショット方式 `ldopengl` に対応 |
| NoxPlayer（夜神） | `127.0.0.1:62001` | 64ビット版は `127.0.0.1:59865` |
| BlueStacks（蓝叠） | `127.0.0.1:5555` | Hyper-V 版は `bluestacks5-hyperv` を指定 |
| MEmu（逍遥） | `127.0.0.1:21503` | — |

Serial が不明な場合は、エミュレーターのインストールディレクトリにある `adb` を使用して `adb devices` コマンドで確認できます。設定に `auto` と入力して自動検出させることも可能ですが、**複数のエミュレーターが同時に起動している環境では使用できません**。

::: tip スクリーンショットおよび操作方式
デフォルトの「自動選択」では、初回実行時にパフォーマンステストを行い最速の方式を選択します。一般的な速度順：`DroidCast_raw` > `aScreenCap_nc` > `ADB_nc` > `aScreenCap` ≈ `uiautomator2`。MuMu および LDPlayer には専用方式（`nemu_ipc`、`ldopengl`）が存在します。操作方式は `MaaTouch` の使用を推奨します。
:::

## <DocIcon name="cloud" /> ネットワーク

| シナリオ | 必要なアクセス先 |
| --- | --- |
| ランチャー初回起動 | GitHub（コアリポジトリ取得）、PyPI またはミラー、npmmirror（Python standalone） |
| Android 完全版 | オフラインで Runtime 展開可能。更新時は GitHub / CNB |
| Android 軽量版 | GitHub Release または CNB（約 1GB の Runtime ダウンロード） |
| 稼働中 | ゲームサーバー、アップデート確認、任意の ilocal/リモートアクセスサービス |

中国本土ネットワーク環境では、ランチャーの `-cn` ミラー版デプロイ設定、または Android 設定内の CNB ダウンロードソースを利用できます。ランチャーはコード更新、依存関係のインストール、ローカル WebUI への接続時にシステムプロキシをバイパスし、ローカルループバックへの干渉を防ぎます。

## <DocIcon name="settings" /> ゲーム内設定 {#游戏内设置}

以下の設定は画像認識とタスク進行に直結するため、**タスク実行前に必ず完了させてください**。

設定画面の開き方：メイン画面 → 右下の「設定」歯車アイコン → 左側サイドバー。

| 設定項目 | 推奨値 | 影響と理由 |
| --- | --- | --- |
| フレームレート | 60 fps | フレームレートが低すぎるとアニメーション完了前にスクリーンショットが撮影されます |
| セイレーン作戦 · TBガイダンス削減 | ON | 大世界突入時の案内ポップアップを削減します |
| セイレーン作戦 · 自律戦闘時のアイテム自動提出 | ON | 倉庫圧迫による自律戦闘の中断を防止します |
| セイレーン作戦 · 安全海域でデフォルト自律戦闘 | OFF | スクリプト自身が自律の要否を判断する必要があります |
| ストーリー自動再生 | ON | オフの場合、ストーリー演出で停止します |
| ストーリー自動再生速度 | 最速 | 待ち時間を短縮します |
| スタンバイモード | OFF | スタンバイ画面への移行による認識失敗を防ぎます |
| 重複艦船獲得時の確認 | OFF | ポップアップによるフローの中断を防止します |
| 装備高速変更の再確認 | OFF | 不要な確認タップを1回削減します |
| リザルト画面での艦船表示 | OFF | リザルト時の画面遮蔽を防ぎます |

### セイレーン作戦（大世界）：潜水艦支援

アクセス手順：セイレーン作戦 → 右上のレーダー → 指令モジュール → 潜水艦支援。**「支援消費時に潜水艦が出撃」のチェックを外してください**。

### 一括退役

アクセス手順：メイン画面 → 建造 → 退役 → 歯車アイコン → 一括退役設定。

| 設定項目 | 推奨値 |
| --- | --- |
| 優先選択順位 1 / 2 / 3 | R / SR / N |
| 最大限界突破同名艦所持時にキープ | キープしない |
| 最大限界突破同名艦未所持時にキープ | 限界突破分キープ または キープしない |

## <DocIcon name="eye" /> 画像認識に関する注意事項

以下の要素はテンプレートマッチングの精度を著しく低下させるため、自動周回用アカウントでは無効化または解除を推奨します：

- <DocIcon name="circle-alert" /> キャラクタースキン・着せ替え
- <DocIcon name="circle-alert" /> キャラクター固有の特殊装備（立ち絵表示領域が変化します）
- <DocIcon name="circle-alert" /> 画面 UI 要素を隠蔽するあらゆるカスタム表示機能

認識失敗が頻発する場合は、まずデフォルトスキンと標準装備に戻した上で、解像度と DPI スケーリングを確認してください。

## <DocIcon name="lock" /> アカウントとセキュリティ

- <DocIcon name="lock" /> WebUI はデフォルトでローカルマシンからのみアクセスを受け付けます。LAN またはインターネットに公開する場合は必ずパスワードを設定してください。未設定のまま公開すると第三者にアカウントを遠隔操作される危険があります。
- <DocIcon name="key" /> リモートアクセスは個別のペアリング認証情報を使用し、WebUI のマスターパスワードは公開されません。ペアリングを取り消してもマスターパスワードには影響しません。
- <DocIcon name="ban" /> `config/remote-access.json`、`config/deploy.yaml`、`password.txt` を Git にコミットしたり他者へ共有しないでください。
- <DocIcon name="lock-keyhole" /> アカウントヴォールトはシステムレベルのキー暗号化（Windows DPAPI / TPM）を使用し、デバイスにバインドされます。別のマシンへ移行した場合は再登録が必要です。
