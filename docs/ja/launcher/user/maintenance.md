# 更新・修復・アンインストール

**ランチャー本体、Git／ADB 部品、AzurPilot コアは別々に更新**されます。ランチャーの更新だけでコアを再インストールしません。

## 更新と設定

設定から正式版の **stable**（既定）またはテスト版の **canary**、更新元の自動・公式・GitHub・Cloudflare CDN を選択します。取得失敗時には他の URL へ切り替え、ハッシュを検証します。背景音声は既定でオフです。アニメーションの低減、スリープ抑止、OS 起動時の動作も設定できます。ウィンドウ非表示時は背景動画を停止します。

## 操作の違い

| 操作 | 内容 |
| --- | --- |
| デプロイ | Git／ADB と deploy スクリプトの取得 |
| 起動 | Python・コア・依存関係・WebUI を準備して後端を起動 |
| 環境修復 | 部品を再ダウンロードし `.venv` を再構築。ソース、`config/`、`log/` は保持 |
| ランチャー更新 | 実行ファイルを更新。ユーザーデータは保持 |

ダウンロード失敗だけでフォルダーを全削除したり、破壊的な Git コマンドを実行しないでください。まず後端を停止して「環境修復」を選びます。ホーム画面からログ ZIP を出力できます。不具合報告には再現方法とログを添えてください。共有前に個人情報を確認してください。

macOS では新しいデータディレクトリ `AzurPilot.app/Contents/AzurPilot` へ旧配置からの移行が行われます。アンインストール／移行前に `config/` と統計をバックアップしてください。

[初回起動](/ja/launcher/user/first-run)と[更新仕様](/ja/launcher/developer/update)を参照してください。
