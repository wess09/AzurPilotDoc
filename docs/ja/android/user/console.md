# コンソール・統計・フローティング・スクリーンセーバー

Android ホストは「詳細設定」と「日常のクイック操作」を明確に分離しています：コンソール画面で完全な設定を行い、フローティングパネルで手軽に開始・停止を操作し、周回中はスクリーンセーバーにより画面焼き付きとバッテリー消費を防止します。

## ネイティブ統計と資源管理

AzurPilot ページの「概要」から「統計」を開くと、Android ネイティブの統計モジュールを利用できます。レポートは現在選択中の Runtime インスタンスごとに分離されます。対応タスクをまだ実行していないカテゴリにはデータが表示されない場合があります。

### 8 種類のレポート

| カテゴリ | 内容 |
| --- | --- |
| 資源トレンド | 資源量とその推移 |
| 大世界トレンド | 大世界の行動に関する推移 |
| 大世界サマリー | 大世界のタスクと資源の集計 |
| 委託報酬 | 委託で獲得した報酬 |
| 艦船 EXP | 艦船経験値の獲得量 |
| 大世界ドロップ | 大世界のドロップ。タスク別に絞り込み可能 |
| 研究ドロップ | 研究報酬。期数別、またはチップ・資金別に表示 |
| 倉庫アイテム | 倉庫アイテムの統計。必要に応じて明示的にスキャンを開始 |

レポートには指標カード、トレンドグラフ、表、注記が含まれます。トレンド範囲は 1 / 7 / 30 / 90 / 365 日から選択できます。大世界レポートは月別、研究は期数またはチップ・資金、大世界ドロップはタスク別に絞り込めます。「再集計」は端末に記録済みの受取データを再集計するだけで、ゲームを再操作しません。CSV 出力にも対応しています。

### 資源管理

1 / 7 / 30 日、または最長 366 日のカスタム期間を選び、資源とタスクで絞り込めます。在庫サマリー、資源フロー図、取引明細を表示します。在庫サマリーでは現在庫、期間内収入、支出、調整値を分けて表示し、調整値はタスクの収支に含めません。各取引には「確認済み」「実測」「認識」「調整」の記録根拠が付き、CSV にも出力できます。

石油制御は個別に有効化でき、目標値は 1,000～24,999 です。現在庫は直近の有効な在庫スナップショットに基づきます。スナップショットがなければ 0 ではなく空欄になります。

倉庫アイテムカテゴリの「倉庫統計を実行」は、明示的に `StorageStatistics` タスクを開始します。レポートの再読み込みは最新の完了済みスナップショットを読むだけで、再スキャンは開始しません。

::: warning リリース状況
ネイティブ統計モジュールは Android `main` のコミット `7b468fb7` で追加されました。2026-11-12 時点の最新公開ローリング APK は `1.3.196`（2026-11-08）で、このコミットより前のものです。`1.3.196` にこれらの画面が含まれるとは限りません。
:::

## <DocIcon name="monitor" /> フローティング操作パネル

FloatingX をベースとしたグローバルオーバーレイパネルであり、他のアプリやホーム画面の上に重ねて表示できます：

| 操作 | 動作 |
| --- | --- |
| タップ | パネルの展開 / 折りたたみ |
| 開始 / 停止 | 選択中のインスタンスの実行を即時切り替え |
| キュー確認 | 現在のタスクとスケジューラーのキュー一覧を表示 |
| インスタンス切替 | 複数インスタンス環境で操作対象を素早く変更 |
| ログストリーム | 直近の実行ログをリアルタイムにスクロール表示 |

フローティングウィンドウは独立したシステム Window であり、Activity のライフサイクルとは分離されています。`AppThemeState` と `OverlayController` を通じて状態を取得するため、アプリ側のテーマ変更には追従しますが、画面固有の一時的な状態は共有しません。

::: tip フローティングパネルが表示されない場合
端末の設定で「他のアプリの上に重ねて表示（オーバーレイ権限）」が付与されているか確認してください。一部のメーカー製 ROM では「バックグラウンドでのポップアップ表示」などの追加権限が必要です。
:::

## <DocIcon name="eye" /> スクリーンセーバー（有機EL焼き付き防止）

バックグラウンド周回中は画面が長時間点灯し続けるため、OLED（有機EL）ディスプレイでは画面の焼き付きリスクが存在します。本機能は以下の保護を提供します：

| 挙動 | パラメータ |
| --- | --- |
| 背景表示 | 真っ黒（純黒表示による発光オフ）および超低輝度 |
| 起動条件 | 手動による切り替え、またはタスク開始時の自動突入 |
| ピクセルシフト | 無操作状態が30秒継続した後、10秒ごとに上下に 16dp 微小ドリフト移動 |
| 解除操作 | 画面下部のアンロックバーを右端までスライドして指を離す |

ドリフト移動は定期的な微小シフトであり、ゲーム自体の動作には影響しません（スクリーンセーバーは仮想ディスプレイの上に描画され、ゲームは内部で動作を継続します）。LCD 端末でも省電力効果が得られます。

## <DocIcon name="box" /> ホーム画面ウィジェット

Glance / RemoteViews ベースのホーム画面ウィジェットに対応しており、周回状態の確認やクイックな開始・停止が可能です。

一部の旧型端末 ROM におけるベクター属性の解決バグを回避するため、ウィジェットはテーマ動的属性に依存せず、明示的な静的 drawable リソースで描画されます。

## <DocIcon name="zap" /> バックグラウンド常駐保活

Android 実機で周回を行う際の最大の障害は、OS 独自の省電力タスクキラーです。本アプリは3重の保護を提供します：

1. **フォアグラウンドサービス**：Runtime または仮想画面がアクティブな間、通知領域に常駐してプロセス優先度を維持。
2. **多経路保活マネージャー**：`KeepAliveManager` が設定に基づき複数の保活パスを統合制御。
3. **バッテリー最適化の除外**：システム設定からユーザーによる明示的な除外認可が必要。

推奨設定チェックリスト：

- システム設定 → バッテリー → アプリバッテリー使用量 → AzurPilot を「制限なし」に設定。
- メーカー固有の「自動起動」「バックグラウンド実行」ホワイトリストに登録。
- 「省電力モード」「バッテリーセーバー」によるバックグラウンド制限を解除。

::: warning 保活機能の限界について
極端なメモリ不足や超省電力モード下では、OS により強制終了される可能性があります。重要な周回を行う際は、定期的に端末の状況を確認するか、PC 環境での実行を検討してください。
:::

## <DocIcon name="scroll" /> ログの管理と出力

3系統のログが分離して記録されます：

| ログ種別 | 格納場所 | 記録内容 |
| --- | --- | --- |
| ホストログ | アプリのプライベートストレージ | Compose UI、ゲートウェイ通信、デプロイ、更新ログ |
| Runtime ログ | `proot/session.log` ＋ コアの `log/` | スケジューラーとゲーム操作ログ |
| 特権起動ログ | 独立したタイムライン記録 | ADB 起動、Binder コールバック、仮想画面管理 |

ログ機能の特徴：

- 異常検知時に現在の画面スクリーンショットを自動保存。
- デフォルトで7日間の自動ローテーション（古いログは自動削除）。
- ワンタップで ZIP 形式にアーカイブしてエクスポート可能。

エクスポート前に、アーカイブ内に `config/deploy.yaml`、`password.txt`、`remote-access.json` などの機密ファイルが含まれていないことを確認してください。

## 端末の互換性レポートを投稿する

「設定 → 端末を投稿」から収集された端末・OS 情報を確認し、利用実績に基づいて「使用可能」または「使用不可」を明示的に選択して、GitHub 公開に同意した後で送信します。[対応端末 Issue #1](https://github.com/wess09/AzurPilot-for-Android/issues/1) にコメントが追加され、重複報告は既存コメントを示します。結果は自動選択されません。

IMEI、シリアル番号、Android ID、MAC、ログ、スクリーンショットは送信しません。情報は送信前に確認してください。公開用の認証情報がないローカルビルドでは送信できない場合があります。[端末報告仕様](https://github.com/wess09/AzurPilot-for-Android/blob/main/doc/device-reporting.md)と[Runtime](/ja/android/developer/runtime)を参照してください。

## <DocIcon name="message" /> よくある質問

| 現象 | 主な原因と対策 |
| --- | --- |
| フローティングパネルをタップしても反応しない | オーバーレイ権限の失効、または省電力機能によるバックグラウンド制限 |
| スクリーンセーバーがピクセルシフトしない | 開発者オプションでアニメーションが無効化されている、または省電力モード中 |
| ウィジェットに古い状態が表示されたまま | ランチャーキャッシュの影響。ウィジェットを一度削除して再配置 |
| 画面消灯後にタスクが中断する | バッテリー最適化が「制限なし」に設定されていない |
| ログエクスポートの結果が空 | ログがすでにローテーション削除されたか、保存先への書き込み権限不足 |
