# WebUI ガイド

WebUI は React + Vite で構築された Web コンソールであり、`/api/v1/ws` を経由してバックエンドと通信します。ゲームを直接操作するのではなく、すべての操作はスケジューラーへのコマンドや設定ファイルへの書き込みとして処理されます。

## <DocIcon name="map" /> 画面マップ

| 画面 | URL パス | 用途 |
| --- | --- | --- |
| ホーム | `/` | インスタンス一覧カード、一括開始/停止、お知らせ |
| ダッシュボード | `/i/<インスタンス>/overview` | 現在のタスク、資材残量、リアルタイムログ、クイック操作 |
| タスク設定 | `/i/<インスタンス>/task/<タスク>` | 設定スキーマから動的生成される設定フォーム |
| 統計レポート | `/i/<インスタンス>/statistics` | 資材推移、出撃、大世界、委託、倉庫アイテム等の統計 |
| 取引所 | `/i/<インスタンス>/stock-exchange` | 取引記録・交換レートの管理モジュール |
| スケジューラー | `/i/<インスタンス>/task/SchedulerProgram` | ビジュアルフローによる実行順序の高度な編排 |
| メンタル計算機 | `/i/<インスタンス>/task/MindCalculator` | ドックスキャンとメンタルユニット必要数の試算 |
| 艦隊技術 | `/i/<インスタンス>/task/FleetTechnology` | 艦隊技術ポイントのスキャンと集計 |
| インスタンス管理 | `/configs` | インスタンスの新規作成、インポート、エクスポート、複製、削除 |
| 設定 | `/settings` | アカウントヴォールト、リモートアクセス、更新、外観設定 |
| アップデータ | `/updater` | コミットの取得とアップデート適用 |
| お知らせ | `/announcement` | バージョン告知やアップデート情報 |

## <DocIcon name="monitor" /> ダッシュボード概要画面

ダッシュボードは「現在の稼働状況」を1画面に集約しています：

- <DocIcon name="clock" /> **現在のタスク**：スケジューラーが `set_task()` を介して通知する実行中タスク名と進捗。
- <DocIcon name="badge-dollar" /> **保有資材**：燃料、資金、ダイヤ、メンタルキューブ、行動力など。
- <DocIcon name="scroll" /> **最新ログ**：worker のリアルタイムログ。ログレベルに応じてカラー表示。
- <DocIcon name="zap" /> **クイック操作**：開始 / 停止 / 再起動、特定タスクの即時実行、最新スクリーンショットの閲覧。

ログ内ではタスク境界が以下のように区切り線で明示されます：

```text
[AzurPilot] 调度器: 开始任务
──────────────── 科研 ────────────────
[AzurPilot] 调度器: 结束任务
```

## <DocIcon name="file-pen" /> タスク設定画面

左側にタスク分類メニュー（通常出撃、イベント、大世界等）、右側に選択中タスクの設定フォームが表示されます。フォームは `argument.yaml` の定義に基づいて動的にレンダリングされます。

### <DocIcon name="clipboard" /> 設定フォームの構成

| セクション | 内容と役割 |
| --- | --- |
| タスク解説 | タスク名の横の「？」アイコン。各機能の目的を解説（i18n の `help` テキスト） |
| スケジューラー設定 | 有効化、通知送信、次回実行時刻、成功/失敗時遅延インターバル、センシティブ設定 |
| 固有タスク設定 | 当該コンテンツ固有の設定（周回海域、使用艦隊、撤退・停止条件など） |
| 保存先 | タスクの周回結果をどの統計テーブルに記録するか |

### <DocIcon name="pencil" /> コントロールとデータ型

| コントロール | 対応するデータ型 | 留意事項 |
| --- | --- | --- |
| チェックボックス | `checkbox` | ブール値。保存と同時に反映 |
| ドロップダウン | `select` / `option` | 選択肢（文字列または数値） |
| テキスト入力 | `input` / `textarea` | 一部フィールドには正規表現による入力検証あり |
| 日時入力 | `datetime` / `time` | フィールドをクリアすると「即座に期限到来」を意味 |

::: tip 設定の保存は非同期で処理されます
エディタ上の変更はキューに積まれて送信され（`config.patch`）、`revision` によるコンフリクト検出が行われます。画面上に「保存完了」が表示されたことを確認してから画面を移動してください。
:::

### <DocIcon name="warning" /> センシティブタスク（Sensitive）

`Scheduler.Sensitive` が有効化されているタスクでエラーが発生した場合、ゲームを自動再起動せず**インスタンス全体を停止**します。`OpsiCrossMonth`、`OpsiObscure`、`OpsiAbyssal` 等ではデフォルトで有効化されています。

## <DocIcon name="zap" /> ビジュアルスケジューラーエディタ

「タスク設定 → システム → 自定义调度」では、ノードグラフによる柔軟なフロー編排が可能です：

- ノードカードの左側が入力ポート、右側が出力ポートです。四角いポートは実行順序を制御し、丸いポートはデータ値を伝達します。
- 範囲選択、複数選択、コピー＆ペースト、Undo/Redo、全選択、結線の削除に対応しています。
- 主要なパラメータ（資材条件、タスク指定、演算子、待機時間、変数）はカード上で直接編集でき、詳細パラメータは右側のプロパティパネルで調整します。
- 実行中のインスタンスにはタスクの安全な境界で自動反映されます。

3つの動作モード：

| モード | 動作仕様 |
| --- | --- |
| 標準スケジュール | 既存の優先度とタイムテーブルを維持。燃料自動調整機能のみを追加利用 |
| 拡張スケジュール | 「有効化されており期限が到来している」タスクの中からノードロジックで選択 |
| 完全掌握 | プログラムが全タスクの実行を自律制御（未有効化のタスクも起動可能） |

::: warning 適用前のシミュレーション検証
エディタにはシミュレーション機能（`scheduler.program.simulate`）が備わっています。実機に接続せず仮想時間とダミー資材でフローを試走できます。必ずシミュレーションで検証してから「プランを適用」をクリックしてください。
:::

## <DocIcon name="eye" /> 統計とリソース管理

SQLite データベースに蓄積された記録を可視化します：資材残量の推移グラフ、出撃回数、ドロップ履歴、大世界での行動力収支、委託・研究の消化数、倉庫アイテム残量。リソース管理画面ではサンキーダイアグラム（資材フロー）や燃料消費目標ラインの可視化も提供されます。

## <DocIcon name="brain" /> メンタル計算機と艦隊技術

- <DocIcon name="brain" /> **メンタル計算機**：ドック画面をスキャンして艦船名とレベルを自動認識し、手動確認の上で必要なメンタルユニット・メンタルコアの費用を算出。JSON / CSV / XLSX の入出力に対応。
- <DocIcon name="medal" /> **艦隊技術**：ドックの艦船情報から技術ポイントをスキャン・集計。

どちらも `MindCalculatorScan` / `FleetTechScan` タスクによりデータを取得します。

## <DocIcon name="settings" /> システム設定

| 設定エリア | 設定内容 |
| --- | --- |
| アカウント | アカウントヴォールト：作成、ロック解除、TPM/システムキーへのバインド |
| リモートアクセス | Cloudflare Quick Tunnel 有効化、ペアリングコード生成、認可端末一覧 |
| 更新 | 現在のコミット、更新確認、ワンクリックアップデート |
| インターフェース | テーマ（ライト/ダーク）、言語選択、背景画像、表示密度 |
| 設定管理 | インスタンス設定ファイルのインポート・エクスポート・削除 |

## <DocIcon name="rainbow" /> 言語とテーマ

- <DocIcon name="message-text" /> 表示言語として `zh-CN`、`zh-TW`、`ja-JP`、`en-US` を公式サポート。
- <DocIcon name="monitor" /> ライトモードおよびダークモードの自動追従に対応。
- <DocIcon name="smartphone" /> スマートフォン等の狭小画面ではサイドバーが自動格納され、フォームは1列レイアウトに切り替わります。

## <DocIcon name="search" /> ショートカットキーと検索

- <DocIcon name="search" /> 画面上部の検索バーから設定項目やタスク名を検索可能（`Ctrl/Cmd + K` で即座にフォーカス）。
- <DocIcon name="settings" /> スケジューラーキャンバス内：`Ctrl/Cmd + Z`（元に戻す）、`Shift + Z`（やり直し）、`Ctrl/Cmd + A`（全選択）、`Esc`（選択解除）、スペースキー ＋ ドラッグ（キャンバス移動）。
