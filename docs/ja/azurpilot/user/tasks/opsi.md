# セイレーン作戦（大世界）

大世界（Operation Siren / オペレーション・サイレン）は、最も高度で複雑な自動化モジュールです：専用の資材体系（行動力、作戦補給コイン、特別補給トークン）、月次リセット周期、多種多様な特殊海域、そして**配下タスクを自動代理するスマートスケジューラー**を備えています。

## <DocIcon name="badge-dollar" /> 資材システムの理解

| 資材 | 略号 | 入手経路 | 運用上の制約 |
| --- | --- | --- | --- |
| 行動力 | AP / `P` / `C` | 自然回復（約600秒で1点、上限200）、港湾補給、燃料交換箱 | 上限超過は自然回復のロスとなる |
| 作戦補給コイン（黄コイン） | `Y` | 海域ドロップ、任務報酬 | コイン補充タスクの目標資材 |
| 特別補給トークン（紫コイン） | — | 秘密海域、深淵海域 | 港湾ショップ限定アイテムとの交換 |

`P` は「判断に使用される総合行動力」を表します：備蓄箱の開封が有効な場合は箱内の行動力も加算され、無効な場合は現在の実所持値 `C` のみが対象となります。

主要なしきい値設定：

| 記号 | 対応する設定キー | 意味 |
| --- | --- | --- |
| `K` | `OpsiScheduling.OperationCoinsPreserve` | 作戦補給コインの目標維持ライン |
| `R` | `OpsiScheduling.OperationCoinsReturnThreshold` | コイン補充時の追加バッファ量 |
| `B` | `OpsiScheduling.ActionPointPreserve` | コイン補充時の行動力維持ライン |
| `L` | `OpsiHazard1Leveling.MinimumActionPointReserve` | 侵食1レベリングの行動力安全下限（デフォルト：200） |
| `M` | 月末整理用保持ライン | 月末の清掃処理時に保持すべき行動力 |

## <DocIcon name="brain" /> スマートスケジューラー（`OpsiScheduling`）

スマートスケジューラーは「単一の作業」ではなく、自律意思決定エンジンです。以下のサブタスクを一括して代行管理します：

- 侵食1レベリング
- 耄耋相接（ネコ周回）
- 秘密海域
- 深淵座標海域
- セイレーン要塞

スマートスケジューラーに管理を委ねた場合、各海域の**攻略設定は各タスク画面の設定値が参照され**、スケジューラー側は「いつ、どの海域に向かうべきか」の判断のみを担当します。

### <DocIcon name="scale" /> 2つの運用モード

| モード | 発動条件 | 動作仕様 |
| --- | --- | --- |
| コイン獲得優先 | `Y < K`、または直前サイクルでコイン収集中 | `Y ≥ K + R` に達するまで補給コイン集めを代行し、達成後に侵食1へ復帰 |
| 行動力自律消化 | コイン目標が未設定、または十分な場合 | `P` と `L` の関係に基づき、侵食1レベリングの実行や行動力補充を判断 |

### <DocIcon name="compass" /> 意思決定の優先順位

```text
当月の海域全開放が未完了 → サーバー日付更新までタスクを延期
  ↓
Y（コイン）/ P（総合行動力）/ C（現行動力）を取得
  ↓
各港湾での行動力補給枠の購入（当月未達分）
  ↓
P ≤ L の場合 → 行動力の補給を試行
  ↓
月末期間の場合 → 月末整理シーケンスを優先
  ↓
海域全開放の代行判定
  ↓
コイン補充 または 行動力消化周回（侵食1等）へ分岐
```

::: warning スマートスケジューラーと配下サブタスクの二重有効化禁止
スマートスケジューラーを有効化している場合、配下のサブタスク（侵食1や要塞など）を通常のスケジューラー上で個別に同時有効化しないでください。同一海域に対してタスクが競合する原因になります。
:::

## <DocIcon name="map" /> 月初の全海域開放（`OpsiExplore`）

| 項目 | 詳細 |
| --- | --- |
| 用途 | 毎月1日のリセット後、全海域の踏破率を 100% まで進め、港湾や各種コンテンツを開放 |
| 前提条件 | セイレーン作戦のストーリー本編を完走済みであること |
| 主要設定 | 踏破ルート、海域の進行順序、`ActionPointPreserve` |
| 動作検証 | 海域の達成度が順次 100% に上昇し、ログにエリア進入とイベント処理が記録されること |
| 注意事項 | 攻略進行中にゲームアプリを手動で操作しないでください |

### <DocIcon name="refresh" /> 遺漏イベント回収（`OpsiExploreCleanup`）

全海域が 100% に達した後、通常海域（安全海域ではない状態）を再度巡回し、取りこぼした探索イベントや敵艦を一括回収します。月内の完了状態が記録されるため、二重に走ることはありません。

## <DocIcon name="calendar" /> デイリー任務と補給交換

| タスク名 | 役割 |
| --- | --- |
| `OpsiDaily` | セイレーン作戦のデイリー任務消化（サーバーリセットに合わせて実行） |
| `OpsiShop` | 各港湾ショップでのアイテム交換（黄コイン / 紫コイン） |
| `OpsiVoucher` | 補給チケット交換 |
| `OpsiAshBeacon` | META 座標解析および余燼信標（META 戦）の自発挑戦 |
| `OpsiAshAssist` | META 戦の救援支援参加 |

ショップ交換の優先順位は `Filter` で設定します。紫コインは入手量に限りがあるため、貴重素材（開発資材・UR設計図など）を最優先に設定してください。

## <DocIcon name="target" /> 秘密海域・深淵・要塞

| タスク名 | 用途 | リセット周期 |
| --- | --- | --- |
| `OpsiObscure` | 秘密海域の座標ログ攻略（紫コイン・装備箱の獲得） | 毎月 |
| `OpsiAbyssal` | 深淵座標海域（最高難易度、高価値設計図等） | 毎月 |
| `OpsiStronghold` | セイレーン要塞（複数回攻撃が必要な大型拠点） | 毎月 |
| `OpsiArchive` | 作戦ファイル座標海域（行動力消費なし） | 毎月 |
| `OpsiMonthBoss` | 月次ボス（エンフォーサー等）の討伐 | 毎月 |

::: danger 3つのセンシティブタスク
`OpsiObscure`、`OpsiAbyssal`、`OpsiCrossMonth` はデフォルトで `Scheduler.Sensitive` がオンになっています。エラー発生時はゲームを無暗に再起動せず、インスタンスを安全停止して座標アイテムの消失を防ぎます。
:::

## <DocIcon name="circle-alert" /> 耄耋相接と侵食1レベリング

| タスク名 | 用途 | 主要設定項目 |
| --- | --- | --- |
| `OpsiMeowfficerFarming` | 耄耋相接（ネコ周回による資材集め） | `ActionPointPreserve`、海域選択、担当艦隊 |
| `OpsiHazard1Leveling` | 侵食度1海域での連続レベリング | `MinimumActionPointReserve`、育成艦隊、停止条件 |

侵食1は長期的な艦船育成の定番海域です：消費行動力が少なく、無限ループが可能で、スマートスケジューラーによる自動制御に対応しています。

## <DocIcon name="refresh" /> 月またぎ処理（`OpsiCrossMonth`）

毎月末のリセット10分前に自動で大世界に入場し、リセットの瞬間を海域内で待機して迎えることで、新月初日の任務・秘密海域・深淵・ネコ周回を即座に消化し、追加の強化資材（金パーツ等）を回収します。

- 実行中は端末を一切手動操作しないでください。
- センシティブタスクとして扱われ、エラー時は即座に停止します。

## <DocIcon name="circle-dollar" /> 行動力あふれ防止（`OpsiPreventActionPointOverflow`）

自然回復によって行動力が上限（200）に達した際、一時的に大世界に入場して行動力を消費します。

- 常時稼働が難しい環境や、普段あまり大世界を触らない場合に有効です。

## <DocIcon name="video" /> 大世界シミュレーター（`OpsiSimulator`）

現在の行動力・資材状態から、モンテカルロ法を用いて一定期間周回を継続した場合の獲得資材をシミュレーション推計する独立ツールです。

## <DocIcon name="lightbulb" /> 推奨される導入順序

```text
OpsiDaily           有効化（毎日の基本）
OpsiShop            有効化（買い忘れ防止）
OpsiExplore         月初に有効化し、100% 達成後に停止
OpsiScheduling      海域全開放完了後に有効化
OpsiHazard1Leveling スマートスケジューラーに制御を一任
OpsiCrossMonth      月末前に設定を完了
```

まずは「大世界デイリー」で基本動作を確認し、月初に全海域を開放した上で、スマートスケジューラーによる自動周回へ移行してください。

## <DocIcon name="message" /> よくあるトラブル

| 現象 | 主な原因と対処法 |
| --- | --- |
| 球面マップ画面で停止する | 海域識別リソースの不一致。コアプログラムを最新版へ更新 |
| 行動力が尽きて動かない | `P ≤ L` かつ補給不可の状態（正常な動作待機です） |
| 黄コインが目標値まで集まらない | 補給タスクが失敗しているか、しきい値 `K + R` が高すぎます |
| 開放進行度が保存されない | 海域から正常退出できていません（完了フラグは退出成功時に保存） |
| スマートスケジューラーが動かない | タスクが無効、または当月の全海域開放が未完了 |
| 月またぎ処理が中断された | センシティブタスクによる安全停止。ログのエラー詳細を確認 |

内部仕様の詳細は[大世界ナビゲーション](/ja/azurpilot/developer/device-vision#大世界导航)および [OSMap 構造](/ja/azurpilot/developer/architecture#分层与边界)を参照してください。
