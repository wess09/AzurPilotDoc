# 大世界（Operation Siren）

::: danger 最初にセイレーン作戦メインストーリーをクリアしてください
**このページの大世界自動化を使う前に、ゲーム内のセイレーン作戦メインストーリーを最後までクリアする必要があります。** 入口を解放しただけ、または一度入場しただけでは条件を満たしません。AzurPilot が代わりにクリアしたり、必ず自動判定したりするものではありません。
:::

## 構成

WebUI の大世界グループには **独立してスケジュールできるタスクが 16 個**あります。共通設定と単独シミュレーターもあります。類似した設定グループの一部はサブ機能です。

| 種別 | 設定 | 内容 |
| --- | --- | --- |
| 共通設定 | **OpsiGeneral** | 行動力購入、燃料制限、修理、イベント、ログ、通知 |
| シミュレーター | **OpsiSimulator** | 収益推計。スケジュールされず、ゲームも操作しません |
| サブ設定 | **OpsiAshAssist、OpsiSmartExplore、OpsiTarget、OpsiCheckLeveling、OpsiFleetAutoChange、OpsiSirenBug、OpsiFleet、OpsiFleetFilter** | 信標、スマート調度、指揮ニャ、侵蝕 1 育成などで利用 |

## 開始前

1. **セイレーン作戦メインストーリーをクリア**し、通常海域を解放します。
2. 解像度を **1280×720**、フレームレートを **60 FPS** に設定します。
3. 「TB ガイドを減らす」「自律時にアイテムを自動提出」を有効にし、「安全海域で自律を既定で有効」は無効にします。
4. ストーリー自動再生を最速にし、待機、重複入手通知、装備変更の再確認、リザルトキャラクター表示を無効にします。
5. 艦隊、潜水支援、修理しきい値、補給資源を確認します。実行中は手動操作しないでください。

::: warning 潜水支援
「大型作戦 → レーダー → 指令モジュール → 潜水支援」で「X 消費時に潜水艦を出撃」のチェックを外します。
:::

## 資源

| 資源 | 意味 |
| --- | --- |
| AP | 約 600 秒ごとに 1 回復、自然上限 200 |
| C | ゲーム内の現在 AP |
| P | スマート調度の判断値。箱の使用が有効なら箱内 AP を含む場合があります |
| Y | 大世界の黄貨 |
| 紫貨 | 隠密・深淵などで得る通貨。大世界ショップで使用 |

保留値：**K** = 黄貨保留（OperationCoinsPreserve）、**R** = 補貨後の回復幅（OperationCoinsReturnThreshold、負数は 0）、**B** = 補貨中の AP 保留（ActionPointPreserve、0 は耄耋相接の値に戻る）、**L** = 侵蝕 1 育成の AP 保留（MinimumActionPointReserve）、**M** = 月末清理の AP 下限。ダッシュボードの AP 合計には行動力箱が含まれます。

## 16 個のスケジュール可能なタスク

| タスク | 用途と主な設定 |
| --- | --- |
| **OpsiDaily** | デイリー任務と報酬。セイレーン研究のスキップ、任務海域保持 |
| **OpsiExplore** | 月次リセット後の海域開拓を 100% まで実行。ルート、海域順序、AP 保留。主線クリアが必要 |
| **OpsiExploreCleanup** | 100% 開拓後に通常海域イベントを追加スキャン。月次チェックポイントは独立 |
| **OpsiShop** | 味方港を巡回して補給を購入。プリセット、カスタムリスト、停止日 |
| **OpsiVoucher** | バウチャーショップ交換。Filter でアーカイブ座標や素材の優先度を設定 |
| **OpsiObscure** | 隠密座標の使用・清理。危険度、強制実行、全体 / レーダースキャン、再開状態 |
| **OpsiAbyssal** | 深淵座標を階層ごとに攻略。艦隊、潜水艦クールダウン、再起動後の再開 |
| **OpsiStronghold** | セイレーン要塞を複数ラウンドで攻略。艦隊交代、潜水支援、修理、補給 |
| **OpsiArchive** | 所持済み座標を処理してバウチャーショップで次を購入。追加条件は下記 |
| **OpsiMonthBoss** | 月次仲裁者 / Boss。通常または通常 + ハード、適応性確認 |
| **OpsiAshBeacon** | META 信標と支援依頼。OpsiAshAssist はサブ設定 |
| **OpsiMeowfficerFarming** | 指定危険海域で指揮ニャ報酬を周回。AP 保留、危険レベル、対象海域 |
| **OpsiHazard1Leveling** | 侵蝕 1 で艦船育成。AP / 黄貨保留、艦隊、停止条件 |
| **OpsiScheduling** | AP、黄貨、月次状態に応じて耄耋相接、隠密、深淵、要塞、侵蝕 1 を代理実行 |
| **OpsiPreventActionPointOverflow** | AP が自然上限に近づくと指定タスクを一時実行。上限 / 下限と対象を設定 |
| **OpsiCrossMonth** | 月次リセット前に入場・待機し、新周期のデイリーや座標を処理。既定はリセット前 10 分 |

### タスクごとの追加条件

このページの全自動化機能には、セイレーン作戦メインストーリーのクリアが共通前提です。さらに次のタスクには追加条件があります。

- **OpsiExplore / OpsiVoucher**：模擬戦とセイレーン試験場を完了する。
- **OpsiDaily、OpsiObscure、OpsiAbyssal、OpsiStronghold、OpsiMonthBoss、OpsiMeowfficerFarming、OpsiArchive**：模擬戦とセイレーン試験場を完了し、セイレーン作戦開拓ミッション（`OpsiExplore`）を有効にするか、ゲーム内でタスクのヘルプに記載されたセイレーン作戦情報アイテム（燃料 5000）を使用する。
- **OpsiShop**：同じ模擬戦・セイレーン試験場、および毎月の海域開拓または記録装置の条件が必要です。メインストーリーをクリアした翌月、港ショップが新仕様に切り替わってから使用できます。
- **OpsiExploreCleanup**：当月の通常海域の開拓率を先に 100% にする。

**OpsiArchive** は所持済みの座標を先に処理してから、バウチャーショップで次の座標を購入します。毎月の海域開拓中は実行を延期します。

## 共通設定とサブ機能

- **OpsiGeneral**：AP 購入回数、燃料制限、修理しきい値、修理パック、イベント、ログ、通知。
- **OpsiFleet / OpsiFleetFilter**：使用艦隊、潜水支援、複数艦隊の優先順位。
- **OpsiSirenBug**：セイレーン研究の有効状態、Resource / Enemy モード、実行艦隊。
- **OpsiTarget**：耄耋相接の対象海域。複数海域は巡回設定が必要。無効・重複・港海域は保護停止の対象。
- **OpsiCheckLeveling / OpsiFleetAutoChange**：練度確認と侵蝕 1 の艦隊変更補助。独立タスクではありません。
- **OpsiAshAssist**：META 信標の支援サブ設定。
- **OpsiSmartExplore**：OpsiScheduling の機能。独立 OpsiExplore と併用できず、既定の黄貨目標モードのみ対応。
- **OpsiSimulator**：設定と統計からモンテカルロ推計を行う分析ツール。戦闘は実行しません。

## スマート調度

**OpsiScheduling は判断ループです。** AP、黄貨、月次進行、サブタスク状態を読み取り、次を決定します。

1. 月次開拓が未完了なら開拓を優先または待機。
2. 当月の港での AP 購入状態を確認。
3. AP が保留値を下回ると、行動力箱や購入を試行。
4. 月末清理では AP 下限を守りながら要塞、隠密、深淵、耄耋相接を代理実行。
5. 黄貨が目標未満なら補貨タスクを実行し、回復幅に達したら通常調度に戻る。
6. その他はサブタスクと AP 条件に応じて育成・資源タスクを配置。

::: warning 個別 Scheduler との競合に注意
OpsiScheduling に任せるサブタスクは、スマート調度側で有効にし、個別ページで設定します。個別 Scheduler も同時に有効にしないでください。
:::

## 推奨手順

1. 主線をクリアし、ゲーム設定と艦隊を準備。
2. **OpsiDaily** のみでナビゲーションと任務処理を確認。
3. 月初に **OpsiExplore** を 100% まで実行し、必要なら Cleanup。
4. ショップ、隠密、深淵、要塞、月次 Boss、耄耋相接を設定。
5. サブタスクと艦隊を確認して **OpsiScheduling** を有効化。
6. 必要な場合のみ **OpsiPreventActionPointOverflow** と **OpsiCrossMonth** を追加。

一度にすべてを有効にせず、個別実行とログ確認の後にスマート調度へ移行してください。

## 安全とトラブルシューティング

- **OpsiObscure、OpsiAbyssal、OpsiCrossMonth** は既定でセンシティブタスクです。異常時はゲームを自動再起動せず、インスタンスを停止します。
- 開拓・月またぎ・座標処理中は手動操作や同じエミュレーターへの別ツール操作を避けてください。
- 侵蝕 1 育成は AP を継続消費します。保留値や艦隊を変える前に資源収支を確認してください。
- AP 不足、購入不可、座標なしによる待機・停止は正常な場合があります。保護を無効にして強制続行しないでください。

| 症状 | 確認事項 |
| --- | --- |
| 海域に入れない / 開拓が進まない | 主線クリア、海域解放、コア版、認識リソース |
| AP 不足で停止 | P / C、行動力箱、L / B、購入設定 |
| 黄貨が目標に届かない | K + R、補貨タスク、艦隊、座標 |
| 開拓進行が保存されない | 海域を正常に退出したか |
| スマート調度が引き継がない | OpsiScheduling、サブタスク、月次開拓状態 |
| アーカイブが動かない | 主線、模擬戦、セイレーン試験場、座標 / 白票 |
| センシティブタスクで停止 | ログとスクリーンショットを確認して手動復旧 |
